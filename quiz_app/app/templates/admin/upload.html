Upload Question Bank

Questions use the SQE five-option format (Answer A–E). Upload a .csv (or tab-separated .tsv) file using the columns below.

⬇ Download CSV template  Includes the header row and two worked example rows to overwrite.

Required columns

  • Question ID — a unique reference, e.g. MYSET-FLK1-001
  • Paper — FLK1 or FLK2
  • Primary Topic — must match a subject name for that paper (e.g. Contract Law, Land Law, Business Law and Practice)
  • Question — the scenario / question text
  • Answer A, Answer B, Answer C, Answer D, Answer E — all five options
  • Correct Answer — one letter, A–E

Optional columns

  • Subtopic, Explanation, Authority
  • Source Type, Source Set, Source Question ID
  • Review Status — Draft, Legally Reviewed, Review Due, Official Source, Retired
  • Difficulty — easy / medium / hard
  • Active — true / false (defaults to true)

Legacy four-option files (Topic + Answer A–D, no Paper) are still accepted for backward compatibility.
