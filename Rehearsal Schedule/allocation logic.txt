Allocation spec (proposed)
0) Inputs & normalization

Works sheet

Required: Title

Flexible headers:

Duration → minutes. Accepts 390, 6:30, hh:mm, mm:ss, Excel times.

Difficulty → numeric weight (default 1.0 if missing or blank).

Instrumentation detection (any positive value / non-blank truthy):

Percussion/Timpani → Percs

Piano/Celesta/Keyboard → Piano

Harp → Harp

Brass section present → Brass (any of Horn/Trumpet/Trombone/Tuba > 0)

Canonical columns (created during load):

duration_norm (minutes), difficulty_norm (≥ 0.1)

Section flags are inferred per work: needs.Percs|Piano|Harp|Brass (booleans)

Rehearsals sheet

Required: Rehearsal (1,2,3,…)

Optional: Date, Start Time, End Time, Break

Times parsed to minutes; capacity = (End–Start) – Break.

Mixed Break formats supported: 15, "15", "00:15".

Optional Y/N flags: Percs, Piano, Harp, Brass.

Normalized truthy: Y/YES/TRUE/T/1 (case-insensitive).

Granularity G minutes (default 5). All allocated minutes are multiples of G.

Each rehearsal capacity is snapped to a multiple of G; any remainder < G is recorded as “unschedulable remainder”.

4) Output & guarantees

Per-rehearsal minutes per work (columns Rehearsal k), plus a summary block per rehearsal:

Capacity (snapped), Used, Remaining (ideally 0 except <G).

Per-work Required Minutes equals sum across rehearsals within ([ \text{req}_i, \text{req}_i + \epsilon\cdot\text{req}_i ]`.

Warnings:

If a work cannot meet its required minutes due to global capacity, report unmet minutes.

If a requiring work could not be scheduled on any Y night for a needed section, report the shortfall.

If a rehearsal has an unschedulable remainder < G, record it (informational).

5) Tunable parameters (with suggested defaults)

G granularity (minutes): 5

Specialist night multiplier MULT_Y: 3.0

Min per appearance factor α: 0.25

Max per appearance factor β: 2.0 (can be 3.0 if you want easier full utilization)

Spread penalty λ: 1.0

Recency bonus: 0.6

Extra fill allowance ε: 10%

All of these will live at the top of the file so you can tweak behavior quickly.

6) Edge‑case behavior (explicit)

If either first or last rehearsal cannot include all works with at least G, we ensure that across first+last combined every work appears at least once; the proportional split still fills each to capacity.

If there are no Y nights for a section that some works require, those works are scheduled normally on non‑Y nights (with a warning).

If a rehearsal’s capacity is not a multiple of G, we snap down to the nearest multiple; the shaved remainder is reported.
